# 📊 Power BI Mini Project — Financial Sales Dashboard

## Project Overview
An end-to-end Power BI dashboard built on the Microsoft Financial Sample dataset, 
covering data ingestion, Power Query transformation, DAX modeling, 
and 4-page interactive dashboard development.

## Dashboard Pages
| Page | Name | Key Visuals |
|------|------|-------------|
| 1 | Financial Overview | KPI Cards, Bar Chart, Line Chart |
| 2 | Product & Segment Analysis | Donut Chart, Column Chart, Matrix |
| 3 | Country & Discount Analysis | Stacked Bar, Column Chart, Donut |
| 4 | Yearly Trends & Performance | Line Chart, Area Chart, Column Chart |

## Key Metrics
- 💰 Total Sales: 118.73M
- 📈 Total Profit: 16.89M
- 📦 Total Units Sold: 1.13M
- 🏭 Total COGS: 101.83M

## Key Insights
- Government segment contributes 44% of total sales
- Paseo is the top product with 4.8M profit
- USA and Canada lead with 25M each in sales
- 2014 significantly outperformed 2013 across all segments

## Tools Used
- Microsoft Power BI Desktop
- Power Query Editor
- DAX (Data Analysis Expressions)
- Microsoft Excel
- Power BI Service
